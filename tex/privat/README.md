# Material privado

Documentos `.tex` reales —no borradores— que **no se publican nunca**: notas de
clase, originales de cuadernillos, material de referencia propio.

Se versionan (están aquí para estar a salvo), pero ni `build.py` ni el índice
web los miran. La diferencia con `draft/`:

| Carpeta | Qué es |
|---|---|
| `privat/` | documentos acabados que no quieres publicar |
| `draft/` | material a medias, sin decidir qué será |

Los PDF de esta carpeta también están exceptuados del `.gitignore`, por si
guardas originales sin fuente.
